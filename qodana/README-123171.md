## 1. Tabela de mapeamento

| Code Smell (Fowler) | Inspeção no IntelliJ/Qodana | ID da inspeção | Métrica / Limiar | Limitações |
|---|---|---|---|---|
| Long Method | Overly long method | A confirmar no perfil YAML | LOC — número de linhas de código do método | A inspeção utiliza um limite absoluto de linhas e não combina automaticamente diferentes métricas para identificar o cheiro. |

## 2. Configuração do Quality Gate

Foi utilizado o Qodana for JVM Community para analisar o projeto Java Battleship2, com um perfil de inspeção personalizado para identificar métodos excessivamente longos.

O quality gate foi integrado no GitHub Actions, permitindo executar automaticamente a análise durante os processos de push e pull request.
